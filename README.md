# Shared-momentum network, extended

Put this folder inside the Capstone repository (next to `paper_replication/`) and open `Momentum_Network_Extended.ipynb`.

- `inputs.py`, `network.py`, `scoring.py`, `plots.py`: the notebook's code.
- `runs/`: cache of the rolling refits. Delete it to refit (about 12 minutes on two cores).
- Needs `torch`, `plotly`, `pandas`, `numpy` and the packages of `paper_replication`.
